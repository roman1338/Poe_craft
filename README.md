# PoE Crafter

A Path of Exile Alt / Aug crafting simulator, modifier database explorer, and Ctrl+C item regex matcher inspired by Craft of Exile.

## Features
- **Modifier Database Explorer:** Browse all item classes (Amulets, Body Armours, Weapons, Boots, etc.), filter by Prefix/Suffix/Influence, search patterns, view detailed tier ranges (T1–T10, ilvl, min/max values), and generate exact in-game search regexes.
- **Crafting Simulator:** Interactive Alt / Aug magic item crafting engine with authentic Path of Exile roll mechanics, tier probabilities, and auto-crafting loop.
- **PoE Item Ctrl+C Analyzer:** Paste clipboard item dumps from Path of Exile to extract explicit modifiers, check goal match status, and get instant recommendations (Alteration, Augmentation, or Target Found).
- **Settings & Calibration:** Configure action delays, Alt-key swap mode, humanized jitter, and export/import `settings.json`.

## Hotkeys
- `F6`: Item position calibration
- `F7`: Roll Alteration Orb
- `F10`: Roll Augmentation Orb
- `F8`: Start Auto-Craft
- `F9`: Stop Auto-Craft
